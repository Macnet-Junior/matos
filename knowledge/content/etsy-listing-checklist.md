# Etsy listing checklist

Use with `etsy-listing-lab`. Human-gated — no live publish.

## Before draft

- [ ] Offer brief locked (what it is, who it’s for, price band)
- [ ] Proof assets collected (photos, mockups, receipts)
- [ ] Brand voice skimmed (`knowledge/brand/voice.md`)
- [ ] Offer mapped on ladder (`knowledge/monetization/offers.md`)

## Draft

- [ ] Title ≤ 140 chars, searchable nouns first
- [ ] 13 tags: mix of broad + niche; no spam repeats
- [ ] Description: hook → benefits → what’s included → shipping/FAQ
- [ ] Primary image ranked; alt text noted for later

## Review gate (Warm)

- [ ] Claims match evidence links on the skill
- [ ] CTA does not promise auto-fulfillment
- [ ] Owner approve — never auto-publish
