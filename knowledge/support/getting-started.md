# Getting started with MatOS

MatOS is a company operating layer — map, skills, workflows, and channels.

## Login

Use your seeded email and password `dev` locally. Owner: `macnet@matos.local`.

## First steps

1. Open **Company map** to see departments and skills.
2. Browse **Knowledge** for brand voice and content stubs.
3. Run a **Workflow** dry-run from Workflows (Operator/Owner).
4. Connect channels under **Settings → Channels** when you have API keys.

## Roles

- **Owner** — full control
- **Operator** — run + approve workflows, ops meters
- **Author** — edit skills
- **Viewer** — read + open support tickets/chat
